# Workspace Guidelines & Agent Behavior

## Autonomy and Permissions
- **Autonomous Execution**: Never ask for user permission or conversational confirmation before performing read-only operations (viewing files, searching code, listing directories) or making requested file edits within this repository.
- **Direct Implementation**: Execute necessary code changes directly and present the completed work without pausing for intermediate confirmation, unless a critical ambiguity or destructive out-of-workspace action is involved.
